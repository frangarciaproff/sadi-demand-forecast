# sadi-demand-forecast

Work in progress. Day-ahead forecasting of Argentina's interconnected grid (SADI) electricity demand,
run as a monitored service on AWS.

The design is in [SPEC.md](SPEC.md) (draft) and decisions are logged in [docs/DECISIONS.md](docs/DECISIONS.md).
This README will be written from real results only, once they exist.

Data: CAMMESA (published information; raw data is not redistributed) and Open-Meteo (CC BY 4.0).
